# Proyecto 

Este repositorio contiene un proyecto Java con Maven que implementa **GitHub Actions**, **JaCoCo** y **SonarCloud**.

## Integrantes del Equipo
* **Duvan Duarte** - *Rol: Configuración inicial del proyecto y estructuras de prueba*
* **Daniel Gonzalez** - *Rol: Integración de GitHub Actions y configuración de SonarCloud*
* **Gabriel Arteaga** - *Rol: Demostración de fallos CI/CD, corrección y entrega multimedia*

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Java 17/21
* **Gestor de dependencias:** Apache Maven
* **Pruebas unitarias:** JUnit 5
* **Cobertura de código:** JaCoCo Plugin (mínimo 95% de cobertura)
* **Análisis estático:** SonarCloud
* **CI/CD Pipeline:** GitHub Actions
